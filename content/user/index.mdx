## Mulai dalam 3 Langkah

<Steps>
<Step>

### 1. Login
Buka [memoryquiz.gameforsmart.com](https://memoryquiz.gameforsmart.com). Klik **Continue with Google** atau isi **Email / Username + Password**, lalu **LOGIN**.

<figure className="overflow-hidden rounded-xl border border-fd-border bg-fd-card my-4">
  <img src="/window/login.png" alt="Halaman login MemoryQuiz versi live" className="w-full object-cover" loading="lazy" />
  <figcaption className="px-3 py-2 text-xs text-fd-muted-foreground text-center">Halaman login — pilih Google atau Email/Username</figcaption>
</figure>

</Step>
<Step>

### 2. Buat atau Gabung
**Host:** klik **CREATE GAME** → pilih kuis → bagikan Room Code.
<br></br>
**Player:** cari **Join Game** → masukkan 6-digit kode dari Host.

<figure className="overflow-hidden rounded-xl border border-fd-border bg-fd-card my-4">
  <img src="/window/join.png" alt="Halaman Join Game — masukkan Room Code 6 digit" className="w-full object-cover" loading="lazy" />
  <figcaption className="px-3 py-2 text-xs text-fd-muted-foreground text-center">Player masukkan 6-digit Room Code di halaman Join Game</figcaption>
</figure>

</Step>
<Step>

### 3. Main & Menang
Cocokkan sepasang kartu yang sama untuk membuka soal, lalu jawab cepat dan tepat untuk naik ke puncak leaderboard!

<figure className="overflow-hidden rounded-xl border border-fd-border bg-fd-card my-4">
  <img src="/window/kuisGame.png" alt="Gameplay MemoryQuiz — cocokkan kartu untuk membuka kuis" className="w-full object-cover" loading="lazy" />
  <figcaption className="px-3 py-2 text-xs text-fd-muted-foreground text-center">Cocokkan kartu → soal terbuka → jawab untuk dapat skor</figcaption>
</figure>

</Step>
</Steps>

## Sekilas Aturan Main

| Fase | Yang Dilakukan | Tips |
| --- | --- | --- |
| 👀 Observasi | Hafalkan posisi kartu saat sempat terbuka | Fokus ke 2–3 pasang dulu |
| 🃏 Pencocokan | Balik 2 kartu, cocokkan gambar yang sama | Jangan asal klik |
| ❓ Quiz | Jawab 1 dari 4 opsi (A–D) secepat mungkin | Kecepatan + ketepatan = skor maksimal |
