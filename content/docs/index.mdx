# Pengantar Tutorial

Selamat datang di situs **Tutorial GameForSmart**! Situs ini berisi panduan **membangun** setiap game di platform GameForSmart — dari setup lingkungan, frontend, database, backend, autentikasi, sampai deployment — dengan acuan langsung pada kode sumber asli.

Setiap game memiliki tutorial sendiri yang mengikuti siklus pengembangan nyata:

1. **Setup** — install, environment, dan menyiapkan database.
2. **Frontend** — routing halaman, komponen game, dan tampilan.
3. **Database** — skema, RLS, dan Realtime.
4. **Backend** — logika game, API, dan sinkronisasi state.
5. **Login** — autentikasi pengguna.
6. **Deploy** — rilis ke server produksi.
