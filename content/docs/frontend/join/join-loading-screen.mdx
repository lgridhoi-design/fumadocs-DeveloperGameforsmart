# JoinLoadingScreen — Tiga Teks, Satu Kartu

File ini cuma 33 baris dan tidak punya logika jam, timer, atau fetch. Yang dibahas di sini adalah **cara membedakan 3 kondisi tunggu** yang kelihatannya sama tapi penyebabnya beda:

1. `MEMUAT... / MEMERIKSA AKUN` — Supabase Auth belum jawab, Player belum tentu login.
2. `BERGABUNG... / SELAMAT DATANG, X` — Player sudah login + buka link `?room=`, sistem lagi auto-join.
3. `MEMUAT... / MENYIAPKAN HALAMAN GABUNG` — React `Suspense` lagi download kode halaman.

Salah baca teksnya → salah perbaiki. Nyangkut di No.1 berarti cek Auth, nyangkut di No.2 berarti cek kode room, nyangkut di No.3 berarti cek network.

## 1. Lihat Hasilnya

Tidak ada file PNG karena durasinya 1-5 detik dan butuh kondisi login khusus untuk Playwright. Bentuknya:

```
 ┌─────────────────────────┐
 │  [▶ berputar]           │  kotak putih 64px, Play hitam animate-spin
 │  BERGABUNG...           │  title wajib UPPERCASE pixel-font
 │  SELAMAT DATANG, BUDI   │  subtitle opsional, putih 80%
 └─────────────────────────┘
   belakang: bayangan miring biru-ungu + background pixel gelap
```

Bedakan dari `JoinCard`: kartu ini kecil (`inline-block`, `p-6`, `text-center`), tidak ada input, tidak ada tombol. Kalau ada tombol, berarti kamu salah lihat — itu `JoinCard`, bukan file ini.

## 2. Bedah Sesuai Tiga Pemakaian

<Accordions>
<Accordion title="Pemakaian 1: MEMERIKSA AKUN — jebakan auth">

**Kode pemicu:** `page.tsx:292-299`
```tsx
if (authLoading || !isAuthenticated) return (<JoinLoadingScreen title="MEMUAT..." subtitle="MEMERIKSA AKUN" />)
```
Ditambah `useEffect page.tsx:66-73` yang simpan `sessionStorage.pendingRedirect` lalu `router.push('/login')`.

Artinya: layar ini tampil **sambil** Auth dicek, lalu langsung dibuang ke Login. Player tidak sempat baca lama. Kalau layar ini nyangkut > 3 detik, bukan salah kartu — `useAuth()` / `AuthContext` tidak kunjung jawab (Supabase key salah / offline).

Cara bedakan dengan yang lain: subtitlenya selalu `MEMERIKSA AKUN`, tidak ada nama Player karena nama belum tahu.

</Accordion>

<Accordion title="Pemakaian 2: BERGABUNG — auto-join via link">

**Kode pemicu:** `page.tsx:261-282 + 284-290 + 301-308`.

Alurnya spesifik file ini: `roomCodeParam` ada → `showAutoJoinScreen=true` awal → `useEffect` cek `code.length===6` + `displayName` ada → `handleJoinRoom(code, avatar)` otomatis → sukses → `router.push(waiting)`.

Timer pengaman baris 284: kalau dalam 5 detik `autoJoinFiredRef` tetap false (misal kode 2 huruf), paksa `setShowAutoJoinScreen(false)` agar kembali ke form manual. Tanpa timer ini Player nyangkut selamanya di layar putar.

Subtitlenya dinamis: SELAMAT DATANG + nama Player dalam huruf kapital — satu-satunya pemakaian yang pakai nama. Kalau kamu lihat nama kamu di layar putar, berarti kamu di jalur ini, bukan jalur auth.

Avatar yang dipakai dikunci di `stableAutoJoinAvatarRef` agar tidak berubah di tengah jalan saat `userProfile` telat datang.

</Accordion>

<Accordion title="Pemakaian 3: Suspense fallback — React belum siap">

**Kode pemicu:** `page.tsx:347-356`
```tsx
<Suspense fallback={<JoinLoadingScreen title="MEMUAT..." subtitle="MENYIAPKAN HALAMAN GABUNG" />}>
```

Ini satu-satunya yang di luar `JoinPageContent`. Muncul saat Next.js masih download chunk `useSearchParams` (makanya `page.tsx` dibungkus `Suspense` — aturan Next.js untuk `useSearchParams`).

Bedanya: tidak ada `PageCornerLogos` tambahan? Ada — tetap dibungkus `<GameBackground>`, jadi logo pojok tetap ada. Teksnya `MENYIAPKAN HALAMAN GABUNG`, bukan `MEMERIKSA AKUN`. Kalau kamu throttle ke Slow 3G baru terlihat; di wifi kencang tidak sempat terlihat.

</Accordion>

<Accordion title="Isi kartu: kenapa Play + rotate-1 + border-4?">

**Kode yang dibahas:** baris 20-31.

- Parent `min-h-screen flex items-center justify-center` (baris 20): selalu tengah vertikal, bahkan di HP pendek.
- Bayangan `absolute inset-0 rotate-1 from-blue-600` (baris 22) + badan `relative from-blue-500 border-4` (baris 23): teknik yang sama dengan `JoinCard`, sengaja disamakan agar transisi loading → form tidak jarring warnanya.
- Ikon `Play h-8 w-8 animate-spin` di kotak putih 64px (baris 24-26): dipilih Play karena temanya game; diputar via `animate-spin` agar jelas hidup. Bukan tombol — tidak ada `onClick`.
- `title` wajib, `subtitle?` opsional (baris 13-16). Selalu UPPERCASE + `pixel-font` agar arcade. Jangan kirim kalimat panjang — kartu `inline-block` akan melebar jelek di mobile.

</Accordion>
</Accordions>

3. Kembalikan ke No throttling → hilang cepat. Ini murni kecepatan download JS, bukan Auth.
</Tab>

```tsx
import { Play } from "lucide-react"

interface JoinLoadingScreenProps {
  title: string
  subtitle?: string
}

export function JoinLoadingScreen({ title, subtitle }: JoinLoadingScreenProps) {
  return (
    <div className="min-h-screen flex items-center justify-center">
      <div className="relative inline-block">
        <div className="absolute inset-0 bg-linear-to-br from-blue-600 to-purple-600 rounded-lg transform rotate-1 pixel-button-shadow"></div>
        <div className="relative bg-linear-to-br from-blue-500 to-purple-500 rounded-lg border-4 border-black shadow-2xl p-6">
          <div className="w-16 h-16 mx-auto bg-white border-2 border-black rounded flex items-center justify-center mb-4">
            <Play className="h-8 w-8 text-black animate-spin" />
          </div>
          <h3 className="text-lg font-bold text-white mb-2 pixel-font">{title}</h3>
          <p className="text-white/80 pixel-font-sm">{subtitle}</p>
        </div>
      </div>
    </div>
  )
}
```
