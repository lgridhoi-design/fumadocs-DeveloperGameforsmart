# JoinCard — Formulir Kertasnya Player

File ini membahas **satu kartu form**, bukan satu halaman. Bedanya dengan `app/join/page.tsx`: `page.tsx` urus izin + Supabase, file ini urus **ketikan, tampilan error, dan klik**.

Kalau diibaratkan formulir kertas: `page.tsx` adalah petugas yang verifikasi ke server, `join-card.tsx` adalah kertasnya — kotak isian, kotak centang avatar, tombol kumpul.

## 2. Bedah Sesuai Blok Form

<Accordions>
<Accordion title="Blok nama: BERMAIN SEBAGAI — rantai avatar 3 tingkat">

**Kode yang dibahas:** baris 48 + 61-87.

Baris 48 `const avatar = selectedAvatar || profileAvatarUrl` adalah intinya: pilihan manual menang atas foto Google. Kalau keduanya kosong, jatuh ke huruf inisial `displayName.charAt(0)` baris 77.

Kenapa begini? Karena `page.tsx:91-94` otomatis mengisi `selectedAvatar` dari `userProfile.avatar_url` saat login. Tapi kalau Player sempat klik avatar lain, `userChangedAvatar=true` menghentikan auto-timpa itu. Jadi urutan prioritasnya: klik manual > Google > inisial.

`<PlayerName>` di baris 84 bukan sekadar teks — ia sensor kata kasar + truncate nama panjang agar tidak merusak layout kartu `max-w-md`.

</Accordion>

<Accordion title="Blok kode: input yang menolak simbol">

**Kode yang dibahas:** baris 104-117.

Tiap ketikan lewat saringan ini:
```ts
value.toUpperCase().replace(/[^A-Z0-9]/g, '')
if (value.length <= 6) onRoomCodeChange(value)
```
Artinya: ketik `k7-p2!ma` → tampil `K7P2MA`. Spasi, strip, emoji dibuang diam-diam. `maxLength={6}` + cek `<=6` dobel agar paste panjang tidak jebol.

`onPaste` (baris 114) lebih pintar lagi: paste link `https://.../join?room=K7P2MA&x=1` → `extractRoomCodeFromUrl` di `page.tsx:96-100` ambil 6 digit via regex `/\b\d{6}\b/` — tapi perhatikan, regex itu cuma cocok digit murni. Kalau kode Host ada huruf (misal `K7P2MA`), paste link tidak akan ke-extract dan input tetap kosong. Itu keterbatasan nyata kode ini, bukan fitur.

Styling `font-mono tracking-wider text-center text-xl` sengaja agar kode terbaca seperti kode voucher, bukan seperti paragraf.

</Accordion>

<Accordion title="Tombol SCAN di sebelah label — bukan hiasan">

**Kode yang dibahas:** baris 95-102.

Tombol ini putih kecil dengan `<Camera className="h-4 w-4">`. Kliknya tidak scan sendiri — ia cuma panggil `onScan` → `page.tsx:326 setShowScanner(true)` → baru `<QRScanner>` dari `html5-qrcode` yang buka kamera.

Hasil scan kembali lewat `handleQRScan` di `page.tsx:249`: ekstrak kode → `setRoomCode` → langsung `handleJoinRoom` tanpa perlu klik GABUNG lagi. Jadi SCAN = isi + submit sekaligus, sedangkan ketik manual = isi dulu, submit belakangan.

Kalau kamera ditolak browser, tidak ada error merah di sini — Player tinggal ketik manual. Itu fallback yang disengaja.

</Accordion>

<Accordion title="Blok avatar: PILIH AVATAR — grid dari file lain">

**Kode yang dibahas:** baris 131-142.

File ini tidak menggambar satu pun avatar. Ia cuma sediakan kotak putih + panggil AvatarSelector dengan tiga props: selectedAvatar, onAvatarSelect, externalAvatar. Gambar gridnya ada di components/join/avatar-selector.tsx.

Props externalAvatar dipakai agar foto Google muncul sebagai opsi pertama di grid. Klik salah satu → onAvatarSelect → page.tsx baris 327 set avatar + tandai userChangedAvatar agar tidak ditimpa lagi.

</Accordion>

<Accordion title="Tombol hijau + 2 box merah — beda merah beda arti">

**Kode yang dibahas:** baris 119-152.

Dua box merah kelihatan sama tapi sumbernya beda:
- `roomCodeError` (baris 119): masalah format lokal — contoh `Kode ruang harus diisi` dari `page.tsx:129`. Muncul tanpa perlu internet.
- `roomError` (baris 124): masalah server — `Ruang tidak ditemukan`, `Game sudah dimulai`, `Anda tidak terdaftar...` dari `page.tsx:142-158`. Butuh `roomManager.getRoom()` gagal dulu.

Tombol hijau baris 145:
```tsx
disabled={isJoining || !roomCode.trim()}
{isJoining ? "BERGABUNG..." : "GABUNG RUANG"}
```
- Kosong → mati (abu, tidak bisa klik).
- Terisi → hijau `bg-green-500 hover:scale-105`.
- Diklik → `isJoining=true` → teks jadi `BERGABUNG...` + mati lagi agar tidak double-submit. Pengaman ganda ada di `page.tsx:112 isJoiningRef`.

</Accordion>
</Accordions>

<Callout title="Cara baca file ini">
Jangan baca dari atas ke bawah. Baca dari tombol hijau ke atas: tombol panggil `onJoin` → `onJoin` butuh `roomCode` → `roomCode` berasal dari input + paste + scan. Kalau tombol tidak aktif, telusuri ke atas: pasti `roomCode` kosong atau `isJoining` nyangkut.
</Callout>

## 3. Uji Sesuai Perilaku Form Ini

<Tabs items={['Saringan Ketikan', 'Dua Merah', 'Tombol Mati-Hidup']}>
<Tab value="Saringan Ketikan">
1. Klik input, ketik `ab! 12cd34ef` → harus jadi `AB12CD` (maks 6, simbol hilang, upper)
2. Paste link panjang berisi 6 digit → terisi 6 digit saja
3. Paste kode huruf campur misal `K7P2MA` sebagai link → tidak terisi (keterbatasan regex digit-only, catat sebagai bug untuk diperbaiki)
</Tab>
<Tab value="Dua Merah">
1. Kosongkan input, klik GABUNG (kalau bisa) → harus `roomCodeError`: *Kode ruang harus diisi*
2. Isi kode ngawur `ZZZZZZ`, klik GABUNG → harus `roomError`: *Ruang tidak ditemukan*
3. Perhatikan: error pertama tanpa loading, error kedua ada jeda loading karena panggil Supabase
</Tab>
<Tab value="Tombol Mati-Hidup">
1. Kosong → tombol mati, hover tidak membesar
2. Isi 1 huruf → langsung hidup hijau
3. Klik 2x cepat → tetap 1 request (karena `isJoiningRef`), teks berubah jadi `BERGABUNG...`
</Tab>
</Tabs>

## 5. Kode Lengkap

#### app/join/components/join-card.tsx

```tsx
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Camera } from "lucide-react"
import Image from "next/image"
import { AvatarSelector } from "@/components/join/avatar-selector"
import PlayerName from '@/components/player/player-name'

interface JoinCardProps {
  roomCode: string
  roomCodeError: string
  roomError: string
  selectedAvatar: string
  profileAvatarUrl?: string | null
  displayName: string
  isJoining: boolean
  onRoomCodeChange: (value: string) => void
  onPaste: (e: React.ClipboardEvent) => void
  onScan: () => void
  onAvatarSelect: (avatar: string) => void
  onJoin: () => void
}

export function JoinCard({
  roomCode,
  roomCodeError,
  roomError,
  selectedAvatar,
  profileAvatarUrl,
  displayName,
  isJoining,
  onRoomCodeChange,
  onPaste,
  onScan,
  onAvatarSelect,
  onJoin,
}: JoinCardProps) {
  const avatar = selectedAvatar || profileAvatarUrl

  return (
    <div className="relative pixel-card-container">
      <div className="absolute inset-0 bg-linear-to-br from-blue-600 to-purple-600 rounded-lg transform rotate-1 pixel-card-shadow"></div>
      <div className="relative bg-linear-to-br from-blue-500 to-purple-500 rounded-lg border-2 sm:border-4 border-black shadow-2xl pixel-card-main">
        <div className="p-4 sm:p-6 space-y-4 sm:space-y-6">
          <div className="text-center space-y-2">
            <div className="inline-block bg-white rounded px-3 sm:px-4 py-1 sm:py-2 border-2 border-black transform -rotate-1 shadow-lg">
              <h2 className="text-lg sm:text-xl font-bold text-black pixel-font">GABUNG RUANG</h2>
            </div>
          </div>

          <div className="bg-white border-2 border-black rounded p-3 sm:p-4">
            <div className="flex items-center gap-3">
              <div className="w-12 h-12 shrink-0">
                {avatar ? (
                  <div className="relative w-full h-full rounded-full border-2 border-black overflow-hidden">
                    <Image
                      src={avatar}
                      alt="Avatar"
                      fill
                      className="object-cover"
                      sizes="48px"
                    />
                  </div>
                ) : (
                  <div className="w-full h-full bg-linear-to-br from-blue-400 to-purple-400 rounded-full flex items-center justify-center border-2 border-white">
                    <span className="text-white text-xl font-bold pixel-font">
                      {displayName.charAt(0).toUpperCase()}
                    </span>
                  </div>
                )}
              </div>
              <div className="flex-1 min-w-0">
                <p className="text-black/50 font-bold text-xs sm:text-sm">BERMAIN SEBAGAI</p>
                <PlayerName name={displayName} className="text-black text-base sm:text-2xl font-bold mt-0.5 truncate w-full block" uppercase={false} />
              </div>
            </div>
          </div>

          <div className="space-y-3 sm:space-y-4">
            <div className="space-y-2">
              <div className="flex items-center justify-between">
                <div className="inline-block bg-white rounded px-2 py-1 border border-black">
                  <Label htmlFor="roomCode" className="text-black font-bold text-xs sm:text-sm">KODE RUANG</Label>
                </div>
                <Button
                  type="button"
                  onClick={onScan}
                  className="flex items-center gap-2 bg-white hover:bg-gray-100 border-2 border-black rounded px-3 py-1 text-black font-bold text-xs sm:text-sm transform hover:scale-105 transition-all duration-200 min-h-9"
                >
                  <Camera className="h-4 w-4" />
                  <span>SCAN</span>
                </Button>
              </div>
              <div className="relative">
                <Input
                  id="roomCode"
                  type="text"
                  placeholder="Masukkan kode ruang 6 digit"
                  value={roomCode}
                  onChange={(e) => {
                    const value = e.target.value.toUpperCase().replace(/[^A-Z0-9]/g, '')
                    if (value.length <= 6) onRoomCodeChange(value)
                  }}
                  onPaste={onPaste}
                  maxLength={6}
                  className="bg-white border-2 border-black rounded-none shadow-lg font-mono text-black placeholder:text-gray-500 focus:border-blue-600 h-12 sm:h-auto text-center text-xl tracking-wider"
                />
              </div>
              {roomCodeError && (
                <div className="bg-red-500 border-2 border-black rounded px-3 py-2">
                  <p className="text-xs sm:text-sm text-white font-bold">{roomCodeError}</p>
                </div>
              )}
              {roomError && (
                <div className="bg-red-500 border-2 border-black rounded px-3 py-2">
                  <p className="text-xs sm:text-sm text-white font-bold">{roomError}</p>
                </div>
              )}
            </div>

            <div className="space-y-2">
              <div className="inline-block bg-white rounded px-2 py-1 border border-black">
                <Label className="text-black font-bold text-xs sm:text-sm">PILIH AVATAR</Label>
              </div>
              <div className="bg-white border-2 border-black rounded p-2 sm:p-3">
                <AvatarSelector
                  selectedAvatar={selectedAvatar}
                  onAvatarSelect={onAvatarSelect}
                  externalAvatar={profileAvatarUrl ? profileAvatarUrl : undefined}
                />
              </div>
            </div>

            <div className="pt-3 sm:pt-4">
              <Button
                className="w-full bg-green-500 hover:bg-green-600 border-2 border-black rounded-none shadow-lg font-bold text-black text-base sm:text-lg py-3 transform hover:scale-105 transition-all duration-200 min-h-11"
                onClick={onJoin}
                disabled={isJoining || !roomCode.trim()}
              >
                {isJoining ? "BERGABUNG..." : "GABUNG RUANG"}
              </Button>
            </div>
          </div>
        </div>
      </div>
    </div>
  )
}
```
