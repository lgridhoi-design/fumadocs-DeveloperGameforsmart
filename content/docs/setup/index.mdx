# Setup

Satu halaman untuk seluruh persiapan proyek sebelum logika game ditulis — mengikuti `gfs/Memory-Game`. Target akhir: `npm run dev` jalan di `http://localhost:3002`, `.env.local` terisi, dan 1 project Supabase siap diisi skema di bab [Database](/docs/database).

<Callout title="Prasyarat">
  **Node.js 18+** • **npm** (proyek asli juga punya `yarn.lock`) • **Akun Google** (untuk Supabase + OAuth di bab [Login](/docs/login)) • **1 project Supabase gratis**.
</Callout>

<Steps>
<Step>

### Scaffold Next.js 14

```bash
npx create-next-app@14 memory-game \
  --typescript --tailwind --eslint --app \
  --no-src-dir --import-alias "@/*"
```

| Flag | Alasan |
| --- | --- |
| `@14` (14.2.16) | Kompatibel dengan `@supabase/ssr` |
| `--no-src-dir` | `app/`, `components/`, `lib/` di root, bukan `src/` |
| `--import-alias "@/*"` | Semua import `@/...` mengarah ke root |

Install package inti (sisanya menyusul per bab):

```bash
npm install next@14.2.16 react@^18 react-dom@^18
npm install @supabase/supabase-js @supabase/ssr
npm install zod sonner lucide-react framer-motion
npm install qrcode.react html5-qrcode
```

Port **3002** untuk dev & production (`package.json`):

```json
{ "scripts": { "build": "next build", "dev": "next dev -p 3002", "start": "next start -p 3002" } }
```

Nilai ini juga dipakai `NEXT_PUBLIC_SITE_URL`. `tsconfig.json` bawaan scaffold sudah benar selama `paths` = `@/*` → `./*`. Opsional seperti proyek asli (`next.config.mjs`):

```js
const nextConfig = {
  eslint: { ignoreDuringBuilds: true },
  typescript: { ignoreBuildErrors: true },
}
```

</Step>
<Step>

### Tailwind v4 + shadcn/ui

Tailwind v4 **tanpa `tailwind.config.js`** — konfigurasi ditulis di CSS. `autoprefixer` tidak dibutuhkan lagi.

```bash
npm install -D tailwindcss @tailwindcss/postcss postcss tw-animate-css
npm install tailwindcss-animate
```

`postcss.config.mjs` — satu plugin saja:

```js
const config = { plugins: { '@tailwindcss/postcss': {} } }
export default config
```

`app/globals.css` — entry point:

```css
@import "tailwindcss";
@import "tw-animate-css";

@custom-variant dark (&:is(.dark *));
```

Font pixel-art (`public/font/`, lalu `@font-face` di awal `globals.css`):

```css
@font-face {
  font-family: 'Press Start 2P';
  src: url('/font/PressStart2P.ttf') format('truetype');
  font-display: swap;
}
/* Duplikat pola yang sama untuk 'LPMQ Misbah' (teks Arab/RTL) */

:root {
  --font-pixel: 'Press Start 2P', cursive;
  --font-system: -apple-system, 'Segoe UI', Roboto, sans-serif;
}
```

Tema warna (`oklch`, pola shadcn):

```css
:root {
  --background: oklch(1 0 0);
  --foreground: oklch(0.3 0 0);
  --primary: oklch(0.65 0.15 45);
  --radius: 0.75rem;
}

@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --color-primary: var(--primary);
}
```

Lalu init shadcn (pilih **new-york** • **neutral** • **css variables: yes**) dan pasang komponen game:

```bash
npx shadcn@latest init
npx shadcn@latest add button card input label badge slider select dialog
npx shadcn@latest add alert-dialog separator progress tooltip toast carousel
```

</Step>
<Step>

### Supabase & `.env.local`

Buat **1 project** di `supabase.com/dashboard` (mis. `memory-quiz-main`, region terdekat), lalu ambil dari **Settings → API**:

| Kunci | Dipakai untuk |
| --- | --- |
| `Project URL` | Endpoint REST/Realtime |
| `anon / public key` | Dari browser, dibatasi RLS — satu-satunya key yang dipakai tutorial ini |

`.env.local` (diabaikan git):

```plaintext
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
NEXT_PUBLIC_SITE_URL=http://localhost:3002
```

`lib/supabase.ts` memakai placeholder agar `npm run build` tidak crash saat env kosong:

```ts
const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL || 'https://placeholder.supabase.co'
const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY || 'placeholder-key'
```

Tegaskan di `next.config.mjs` agar tersedia saat build:

```js
env: {
  NEXT_PUBLIC_SUPABASE_URL: process.env.NEXT_PUBLIC_SUPABASE_URL,
  NEXT_PUBLIC_SUPABASE_ANON_KEY: process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY,
},
```

> Skema SQL (`sessions`, `participants`, `quizzes` + Realtime + RLS) **tidak di sini** — jalankan dari SQL Editor mengikuti bab [Database](/docs/database).

</Step>
